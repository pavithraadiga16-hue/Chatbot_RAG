🔄 Dynamic Field Response
                  Mappings (Scalar fields only)
                

                
Map PhinsIQ Standard Fields → Client ERP JSON
                  Keys. Only for direct scalar values — computed/aggregated fields are handled by the ArrayAggregator.
                

              

              

                ✓
                  Scalar fields only
                ⚡
                  Aggregated — configure in Schema tab
                
                
                
                
              

            


            

              
            

          


          
          

            
⚡ Aggregated Fields — No
              Mapping Needed Here

            

              Fields like absent_count,
              attendance_percentage,
              absent_dates are
              computed automatically by the ArrayAggregator from the ERP array (e.g. attendance_data).
              You do not need to add them here in response_mapping — only add scalar
                fields like start_date and end_date.
              Configure aggregation rules in the 🏷️ Schema & Aliases tab.

                  🤔 Step 1 — Do I need Aggregation for this field?
                

                

                  

                    
📡 SCALAR — No aggregation needed
                    

                    
The ERP returns the value directly as a
                      single number or string.

                    

                      {

                        "pending_amount": 15000,

                        "total_fee": 50000,

                        "start_date": "2026-06-01"

                      }
                    

                    
✅ Just add it in ERP Mapper →
                        response_mapping

                  

                  

                    
⚡ AGGREGATED — Aggregation required
                    

                    
The ERP returns an array of
                        objects. Your field is computed FROM that array (count, filter, %, dates).

                    

                      {

                        "attendance_data": [

                          {"date":"2026-06-03","status":"present"},

                          {"date":"2026-06-08","status":"absent"}

                        ]

                      }
                    

                    
✅ Tick the ⚡ checkbox and fill aggregation config below

                  Operation should I pick?

                      Total number of items in array

                        filter_value

🗓️ Real Example —
                  Adding a Holiday / Calendar Module

                
Say your ERP returns this for the holiday
                  module:

                

                  {

                    "academic_year": "2026-27",

                    "holidays": [

                      { "holiday_date": "2026-08-15", "name": "Independence Day", "type": "national"
                  },

                      { "holiday_date": "2026-10-02", "name": "Gandhi Jayanti", "type": "national"
                  },

                      { "holiday_date": "2026-09-10", "name": "School Annual Day", "type": "school"
                  }

                    ]

                  }
                


                
How to set up 4 fields
                  for this module:

                


                  

                    
Field 1 — total_holidays

                    
📡 Format: text

                    
⚡ Aggregation: ON

                    
🔷 Source Array: holidays

                    
🔷 Operation: count (total items)

                    
No filter needed — just
                      counts all

                    
→ "14 holidays this year"

                  


                  

                    
Field 2 — national_holiday_count
                    

                    
📡 Format: text

                    
⚡ Aggregation: ON

                    
🔷 Source Array: holidays

                    
🔷 Operation: count_where

                    
🔷 Filter Key: type

                    
🔷 Filter Value: national

                    
→ "3 national holidays"

                  


                  

                    
Field 3 — national_holiday_dates
                    

                    
📡 Format: date_list

                    
⚡ Aggregation: ON

                    
🔷 Source Array: holidays

                    
🔷 Operation: filter_dates

                    
🔷 Filter Key: type

                    
🔷 Filter Value: national

                    
🔷 Date Key: holiday_date

                    
→ "15 Aug 2026, 02 Oct 2026"

                  


                  

                    
Field 4 — academic_year (SCALAR)
                    

                    
📡 Format: text

                    
⚡ Aggregation: OFF (it's a direct value)

                    
→ Add
                      academic_year → academic_year in ERP Mapper instead
                    

                    
→ "Academic Year: 2026-27"

                  


                


                

                  
⚠️ Key Rule: How do I know if
                    aggregation is needed?

                  
Look at the ERP JSON. Ask: "Is this field a single value, OR computed from a list of
                      items inside an array?"

                  

                    • If the ERP gives you total_holidays: 14 directly → SCALAR (map it in
                    ERP Mapper)

                    • If the ERP gives you holidays: [...] and you want to count/filter/list →
                    AGGREGATED (tick the ⚡ checkbox)

🚀 Core — Chat Pipeline


        

          

            POST
            /api/v1/phinsiq/chat
            ▼
          

          

            
Main NLP pipeline endpoint. Accepts a natural language question, routes it through
              module detection → ERP fetch → response formatting. Optionally invokes Claude AI fallback.

            

              
Request Body (JSON)

              
messageNatural
                  language query (required)

              
institution_idClient institution key e.g. sjbhs

              
user_idStudent/Staff row_id used for ERP lookup

              
rolestudent | staff

              
use_claudeBoolean.
                  When false, skips Claude entirely

            

            
📤 Request Example

            
{
              "message": "What is my pending fee?",
              "institution_id": "sjbhs",
              "user_id": "ST123",
              "role": "student",
              "use_claude": true
              }

            
            
📥 Response Example

            
{
              "answer": "Your pending fee balance is ₹29,300.",
              "module": "fees",
              "field": "pending_fee",
              "route": "/fees",
              "confidence": 0.97,
              "source": "erp_direct",
              "institution_id": "sjbhs"
              }

            
          

        


        

          

            GET
            /health
            ▼
          

          

            
Server health check. Returns uptime, DB connection status, and version info.

            
📥 Response Example

            
{
              "status": "healthy",
              "version": "2.0.0",
              "db": "connected",
              "uptime_seconds": 3600
              }
